# Stability and Reliability of Explainable AI in IDS

This project evaluates the stability of explainable AI methods applied to machine-learning-based intrusion detection systems.

## Dataset
UNSW-NB15

## Models
Random Forest

## Explainability Methods
- SHAP
- LIME

## Experiments
- Explanation stability under feature perturbations
- SHAP vs LIME comparison
- Stability distribution analysis
- Correct vs incorrect prediction stability
